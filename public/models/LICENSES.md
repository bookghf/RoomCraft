# Model licences

No third-party 3D models, textures or brand assets are bundled with RoomCraft.

All furniture is generated at runtime from three.js primitives (see `src/features/planner/scene/`),
and room shells are generated from the JSON-like data in `src/data/rooms.ts`.

If you add glTF/GLB files to `public/models/`, list each one here with its source, author and licence
(e.g. CC0, CC-BY 4.0 with attribution text) before shipping.
